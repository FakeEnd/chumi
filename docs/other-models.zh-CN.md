# 其他模型：本地或 API

Chumi 通常使用你的 ChatGPT 或 Claude 订阅。你也可以连接本地模型服务或兼容 API，本页介绍配置方法。返回 [README](../README.zh-CN.md#选择-ai)。

Chumi 提供**千问（Qwen）、豆包（Doubao）、MiniMax、GLM、Ollama、LM Studio** 和**自定义兼容 API** 预设，通过兼容的 Chat Completions 接口调用模型。预设只提供初始服务地址，不会自动选择模型，也不包含相应的订阅权益。

## 连接模型服务

1. 打开**设置 → AI 服务**，选择**其他模型：本地或 API**，再选择预设。选择 **Ollama** 或 **LM Studio** 后，Chumi 会自动读取本地服务的模型列表，你可以直接选择模型，无需先填写模型 ID。连接失败或列表为空时，按界面提示安装、启动服务或下载模型，然后点击**刷新模型**。使用远程 API 时，需要填写服务商控制台中的准确模型 ID 或部署 ID。
2. 勾选允许向所选服务发送请求的选项，再点击**保存模型设置**。使用远程 API 时，这也表示允许使用你的服务商账号发送请求，并接受可能产生的费用。各预设的配置分别保存；更改密钥或测试连接前，请先保存或放弃修改。
3. 根据需要保存 API 密钥。密钥按预设和服务地址分别保存：**macOS 使用钥匙串，Windows 使用你的账户加密保存**，均不写入设置。点击**生成简短回答以测试连接**可以检查连接：测试只发送测试文字，不发送会议内容，但可能产生费用。
4. 保存后，确认当前 AI 服务选择的是**其他模型：本地或 API**，后续请求才会使用已保存的模型配置。保存配置和测试连接本身不会切换当前 AI 服务。

展开相应区域，即可配置服务地址、可选的本地 API 密钥和模型高级选项。读取模型列表只会查询模型信息，不会生成回答、下载模型或发送会议内容。

## 选择和下载本地模型

选择本地预设后，**下载前：适合这台电脑的模型**区域会根据检测到的芯片、总内存、用户目录所在磁盘的剩余空间，以及当前选择的语音模型提供建议。你可以比较具体 Qwen3 量化版本的下载大小和运行时的预计内存占用。模型服务尚未安装或启动时，也能查看这些建议。

估算会为系统、其他应用和 Chumi 转写预留内存；上下文越长，预计内存占用越高。这里的上下文选项只影响估算，请在模型管理软件中设置相同的上下文长度。推荐用于评估内存和磁盘容量，不代表实际运行速度，也不保证模型一定能流畅运行。详见[估算依据和来源](local-model-advice.md)。

先安装并启动 Ollama 或 LM Studio，再在 Chumi 中点击**下载推荐模型**。界面会显示下载进度；关闭设置面板后，下载仍会继续，完成后会自动刷新模型列表。Ollama 支持在 Chumi 内取消和重试下载；LM Studio 0.4+ 使用自身的下载接口，暂停或取消需在 LM Studio 中操作。

如果 LM Studio 中的模型下载后仍未出现在列表中，请启用 Just-In-Time loading（按需加载），或在 Developer 中加载该模型。下载不会自动选择或加载模型，请在下拉列表中选择模型并保存设置。

## 图片与结构化输出

图片输入默认关闭。请确认模型和服务地址支持图片输入后再启用，并同时开启“屏幕”设置中的**发送屏幕截图**。

结构化输出默认选择**仅通过提示词约束（推荐）**。只有服务端支持时，才选择 JSON 对象或 JSON Schema 模式。Chumi 不会向兼容服务发送推理强度设置。

## 上下文与请求费用

请在模型服务中设置足够的上下文长度，以容纳会议摘录、笔记和回答。Chumi 不会替你设置服务端的上下文窗口。本地服务也可能向外部转发请求，请检查其配置。兼容模型的推理请求不会自动重试，也不会自动切换到其他服务。

Chumi 无法获知 API 的剩余额度。请查看服务商的计费控制台和条款；订阅聊天应用并不代表拥有相应的 API 使用权益。
